This week featured 13 updates from Microsoft Azure Updates.

Azure updates cover preview and GA features across networking, storage, security, and serverless services.

Detailed list:

* [\[In preview\] Public Preview: Modernize Arc-enabled Windows Servers with Azure File Sync](https://azure.microsoft.com/updates?id=579854). Azure File Sync now offers a guided Azure portal experience for Arc-enabled Windows Server onboarding, simplifying deployment and centralizing file data in Azure. This preview feature streamlines setup, configuration, and storage optimization.
* [Retirement: Support for .NET 8 and .NET 9 on Static Web Apps is ending November 10, 2026](https://azure.microsoft.com/updates?id=575106). Azure Static Web Apps managed Functions APIs will stop receiving security updates and support for .NET 8 and .NET 9 on November 10, 2026, requiring migration to .NET 10.
* [Public Preview: Azure Route Server dual-stack IPv4/IPv6 support](https://azure.microsoft.com/updates?id=579746). Azure Route Server now supports IPv4/IPv6 dual-stack mode in public preview, enabling route exchange for both address families across supported hybrid networking connections. Existing IPv4 connections remain unchanged.
* [\[Launched\] Generally Available: Azure Front Door edge actions](https://azure.microsoft.com/updates?id=579310). Azure Front Door edge actions are now generally available, enabling lightweight JavaScript functions to run at the edge for real-time decisions. They integrate with existing Azure Front Door features and use Hyperlight for secure, isolated execution.
* [\[In preview\] Public Preview: Azure Front Door adds native gRPC support](https://azure.microsoft.com/updates?id=579383). Azure Front Door now supports gRPC in preview, enabling routing of gRPC calls to services and methods, traffic distribution across healthy origins, and use of supported security and routing capabilities. This preview allows gRPC over HTTP/2 and HTTPS with unary and streaming RPCs, and health probes for load balancing.
* [\[Launched\] Generally Available: Azure Functions support for .NET 11](https://azure.microsoft.com/updates?id=578773). Azure Functions now support .NET 11, enabling serverless apps to use the isolated worker model with improved runtime performance, richer APIs, and enhanced developer tooling.
* [\[In preview\] Public Preview: Distributed accelerator for cloud storage on AKS](https://azure.microsoft.com/updates?id=578454). DACS, a distributed read-through cache for Azure Kubernetes Service, is now in public preview for AI workloads, enabling faster model loading and reduced storage reads by caching data locally on NVMe disks.
* [\[In preview\] Public Preview: Rate limit grouping for Azure Front Door Premium WAF](https://azure.microsoft.com/updates?id=580155). Azure Web Application Firewall (WAF) on Azure Front Door Premium now offers a preview feature that groups rate limit rules by shared client attributes, such as JA4 fingerprint, AS number, or country/region, to prevent distributed attacks from evading thresholds. This grouping is optional and does not replace existing per-IP rate limit rules.
* [\[In preview\] Public Preview: SQL performance monitoring for Azure SQL Managed Instance](https://azure.microsoft.com/updates?id=574158). Microsoft-managed performance monitoring for Azure SQL Managed Instance is now in public preview, collecting and storing performance telemetry with resource-level dashboards to identify trends and bottlenecks. It also enables secure KQL queries via an RBAC-protected Azure Data Explorer proxy for deeper analysis.
* [\[In preview\] Public Preview: Auto scaling of ingestion limits in Azure Monitor workspace](https://azure.microsoft.com/updates?id=578207). Auto scaling adds a per-workspace capability in Azure Monitor Workspace to automatically adjust ingestion limits based on usage patterns. This enables dynamic quota adjustments to maintain healthy utilization.
* [\[Launched\] Generally Available: Azure Front Door mutual TLS authentication](https://azure.microsoft.com/updates?id=577678). Azure Front Door Premium now supports mutual TLS (mTLS) client certificate authentication, generally available, enabling secure B2B, IoT, financial, and enterprise scenarios with configurable validation modes.
* [\[In preview\] Public Preview: JWT validation with Azure Front Door Auth Policy](https://azure.microsoft.com/updates?id=577673). Azure Front Door Premium now offers a preview of JWT validation via Auth Policy, enabling edge-based validation of Microsoft Entra ID bearer tokens to centralize authentication and reduce origin traffic. This preview validates existing tokens only; application authorization and origin access remain your responsibility.
* [Retirement: Azure Data Share will be retired on November 12, 2029](https://azure.microsoft.com/updates?id=578818). Azure Data Share will be retired on November 12, 2029, with transition to Microsoft Fabric required. This enables External data sharing, Cross tenant delegated shortcuts, IQ share, and data-source-specific options.
