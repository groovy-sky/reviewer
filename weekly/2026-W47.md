This week featured 175 updates from Microsoft Azure Updates.

This weekly update highlights a broad range of Azure service enhancements, including the general availability of new features like Azure HorizonDB, Azure AI Gateway, and Azure Cosmos DB full-text search, alongside ongoing preview releases such as Azure Functions supporting Node.js and Python, and Azure Monitor Health Models. Notable exceptions include limited preview versions of Azure Functions Flex Consumption and Azure Functions OpenAI support, which are not yet available. The update also emphasizes infrastructure improvements, including Azure Linux 4.0 and Azure Managed Redis, while maintaining a steady pace of new functionality across compute, storage, and security domains.
