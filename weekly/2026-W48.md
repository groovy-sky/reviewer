This week featured 3 updates from Microsoft Devblogs.

AI coding agents face challenges with non-REST APIs, inconsistent documentation, and ranking inconsistencies.

Detailed list:

* [Do AI coding agents struggle with non-REST APIs?](https://devblogs.microsoft.com/blog/do-ai-coding-agents-struggle-with-non-rest-apis/). Non-REST APIs, which use verb-named endpoints and limit methods to GET and POST, do not cause agents to fail more often than REST APIs when agents have access to documentation.
* [Is “sort by impact” just vibes?](https://devblogs.microsoft.com/blog/is-sort-by-impact-just-vibes/). The AI agent now consistently ranks items by impact using a domain-specific definition, avoiding randomness and input order influence.
* [Do inconsistent docs hurt AI coding agents?](https://devblogs.microsoft.com/blog/do-inconsistent-docs-hurt-ai-coding-agents/). The announcement describes a consistency review of Dev Proxy documentation that identified 79 factual contradictions between pages, with fixes applied to resolve them.
