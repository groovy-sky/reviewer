This week featured 28 updates from Microsoft Azure Updates.

Microsoft Azure Updates cover new WAF Insights, wildcard domain support, and AI Gateway enhancements, alongside preview features for model routing and agent insights.

Detailed list:

* [\[Launched\] Generally Available: WAF Insights for Azure Front Door](https://azure.microsoft.com/updates?id=579285). WAF Insights is now generally available for Azure Front Door WAF, providing interactive dashboards to investigate blocked requests, analyze attack patterns, and identify false positives without writing queries.
* [\[Launched\] Generally Available: WAF Insights for Azure Application Gateway](https://azure.microsoft.com/updates?id=579280). WAF Insights for Azure Application Gateway Web Application Firewall is now generally available, providing interactive dashboards that combine WAF logs and metrics to investigate blocked requests, analyze attack patterns, and identify false positives.
* [\[In preview\] Public Preview: Azure Database for PostgreSQL enhanced Burstable tier (Basv2)](https://azure.microsoft.com/updates?id=574535). The enhanced Burstable tier (Basv2) improves performance predictability and burst efficiency, enabling more economical steady workloads with automatic scaling during demand spikes.
* [Retirement: Azure AI Content Safety selected features will be retired on April 30, 2027](https://azure.microsoft.com/updates?id=577474). Azure AI Content Safety preview capabilities, including multimodal custom categories, connected containers, disconnected containers, and safety SDK features, will retire on April 30, 2027. Review recommended alternatives and plan migration accordingly.
* [\[Launched\] Generally Available: Wildcard domain support in Azure Firewall network rules](https://azure.microsoft.com/updates?id=582030). Azure Firewall now supports wildcard domain patterns in network rules, generally available. This enables FQDN-based rules using patterns like \*.contoso.com.
* [\[Launched\] Generally Available: Deploy hosted agents from your own container registry in Foundry Toolkit for VS Code](https://azure.microsoft.com/updates?id=581478). Foundry Toolkit for Visual Studio Code now deploys hosted agents from prebuilt images in customer-managed container registries, including non-Azure registries.
* [\[In preview\] Public Preview: Use model router with AI Gateway](https://azure.microsoft.com/updates?id=581398). Automatic model selection in AI Gateway now uses Microsoft Foundry's model router to rank models behind aliases, enabling selection based on Balanced, Quality, or Cost modes.
* [\[Launched\] Generally Available: Model router now supports the Responses API protocol in Microsoft Foundry](https://azure.microsoft.com/updates?id=581393). Model router in Microsoft Foundry now supports the Responses API protocol in general availability on both resource and project endpoints. It enables automatic model selection for Responses-based applications without switching to Chat Completions.
* [\[In preview\] Public Preview: Use your model deployments with model router in Microsoft Foundry](https://azure.microsoft.com/updates?id=581388). Model router in Microsoft Foundry can serve routed requests using existing model deployments in public preview. It selects a model per request and prioritizes your provisioned throughput, pay-as-you-go, or router-managed capacity.
* [\[In preview\] Public Preview: Use the Messages API with model router in Microsoft Foundry](https://azure.microsoft.com/updates?id=581383). Microsoft Foundry now supports the Messages API in public preview, enabling automatic model selection for Messages-based applications while routing requests only to supported Claude models.
* [\[In preview\] Public Preview: Call model router without a deployment in Microsoft Foundry](https://azure.microsoft.com/updates?id=581378). Microsoft Foundry now allows using model router without deployment, enabling Auto routing with balanced model selection and lower rate limits. Auto is available in regions supporting model router, with admin-configurable settings.
* [\[Launched\] Generally Available: Files knowledge source for Foundry IQ](https://azure.microsoft.com/updates?id=581368). Upload files directly to a managed knowledge source in Foundry IQ, which processes and indexes them for retrieval without provisioning storage or scheduled indexers.
* [\[Launched\] Generally Available: Agent insights in Microsoft Foundry](https://azure.microsoft.com/updates?id=581363). Microsoft Foundry adds insights that analyze agent traces to identify recurring patterns and group related issues, enabling users to investigate common failures and prioritize improvements.
* [\[In preview\] Public Preview: Human annotation for agent evaluations in Microsoft Foundry](https://azure.microsoft.com/updates?id=581358). Human annotation for agent evaluations is available in preview in Microsoft Foundry, enabling reviewers to add ratings, tags, comments, and expected outputs to agent traces.
* [\[Launched\] Public Preview: Style and instruction control for HD V3 voices in Azure Speech in Foundry Tools](https://azure.microsoft.com/updates?id=581353). Azure Speech in Foundry Tools now offers HD V3 voices with style and instruction control in public preview.
* [\[In preview\] Public Preview: IQ Retriever Zero in Foundry IQ](https://azure.microsoft.com/updates?id=581343). Foundry IQ uses an iterative retrieval model to break complex questions into focused searches, reviewing and re-searching results within a configured budget to pass evidence to the answering model.
* [\[In preview\] Public Preview: Updated Guardrails experience in Microsoft Foundry](https://azure.microsoft.com/updates?id=581338). Microsoft Foundry Guardrails adds runtime safety controls for agents, including classifiers and LLM-based judges, and prevents developers from overriding policy-managed settings.
* [\[In preview\] Public Preview: Enterprise Knowledge Graph in Foundry IQ](https://azure.microsoft.com/updates?id=581333). Foundry IQ adds the Enterprise Knowledge Graph as a knowledge source, enabling questions that rely on relationships across content to be answered using extracted entities and relationships from unstructured content.
* [\[In preview\] Public Preview: Central governance of hosted-agent outbound domains in Foundry Agent Service](https://azure.microsoft.com/updates?id=581328). Administrators can use Azure Policy to govern outbound destinations for hosted agents in Foundry Agent Service. The egress policy controls outbound requests at runtime.
* [\[In preview\] Public Preview: Cost controls for model and agent spending in Microsoft Foundry](https://azure.microsoft.com/updates?id=581323). Microsoft Foundry now supports cost controls that set budgets and trigger alerts or block requests when thresholds are reached. Budgets reset daily, weekly, or monthly and apply to usage, projects, or specific deployments.
* [\[In preview\] Public Preview: Azure Developer CLI extension for Azure Document Intelligence and Content Understanding in Foundry Tools](https://azure.microsoft.com/updates?id=581318). Microsoft Foundry now supports azd ai cu commands for analyzing documents using Azure Document Intelligence and Content Understanding, enabling Markdown or JSON output without requiring Python, SDKs, or project initialization. The prebuilt-layout analyzer extracts text and layout without deploying language or embedding models.
* [\[In preview\] Public Preview: Native A2A passthrough for hosted agents in Foundry Agent Service](https://azure.microsoft.com/updates?id=581313). Agent Service now supports A2A passthrough, forwarding native A2A requests directly to your hosted agent container without protocol conversion. This enables direct handling of A2A messages and tasks, with the service managing the endpoint and authentication.
* [\[Launched\] Generally Available: Use Azure Storage permissions in Azure AI Search and Foundry IQ](https://azure.microsoft.com/updates?id=581303). Azure AI Search and Foundry IQ in Microsoft Foundry now uses Azure Storage permissions to control access to search results, enabling content to be returned based on each user's access. This reduces the need for separate security filters and supports both ADLS Gen2 ACLs/RBAC and standard Blob Storage document-level access control.
* [\[In preview\] Public Preview: Govern MCP tools with your own gateway in Microsoft Foundry Agent Service](https://azure.microsoft.com/updates?id=581498). Microsoft Foundry Agent Service allows routing MCP tool traffic through existing AI Gateway or Azure API Management endpoints, enabling centralized control and logging. The preview is for evaluation only and not covered by a production SLA.
* [\[In preview\] Public Preview: Optimize agents from insights in Foundry Agent Service](https://azure.microsoft.com/updates?id=581483). Optimization from insights is in public preview in Foundry Agent Service, enabling generation and evaluation of candidate changes to agent instructions and function-calling tool descriptions.
* [\[Launched\] Generally Available: Azure Site Recovery support for zonal disaster recovery for Ultra disks](https://azure.microsoft.com/updates?id=582171). Azure Site Recovery now supports Zone-to-Zone Disaster Recovery for Azure Ultra disks, enabling replication and recovery of performance-intensive VMs across Availability Zones within the same region. This capability enhances resiliency for mission-critical workloads.
* [Retirement: Support for Java 8, 11 and 17 in Azure Functions ends on September 1, 2027](https://azure.microsoft.com/updates?id=568586). Azure Functions support for Java 8, 11, and 17 ends on September 1, 2027, with no further security updates or customer service. Upgrade to Java 25 to avoid risks and access new features.
* [\[In preview\] Public Preview: ECMP Nexthop](https://azure.microsoft.com/updates?id=582326). ECMP routing for Azure Virtual Network is now available in public preview, allowing traffic distribution across multiple network appliances via a single user-defined route. It supports up to 16 next-hop IPs per route, scaling throughput beyond individual appliance limits.
