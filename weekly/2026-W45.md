This week featured 6 updates from Microsoft Azure Updates.

This week's Azure updates highlight advancements in security, storage, and networking, with several features transitioning to general availability. Notable exceptions include several public preview features, such as JWT validation for Application Gateway for Containers and IPv6 application rules for Azure Firewall, which are still in early access. The rollout also includes new capabilities like multi-disk crash-consistent restore points and enhanced PostgreSQL management, reflecting a mix of mature and emerging enhancements.

Detailed list:

* [\[In preview\] Public Preview: JWT validation for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576382). Application Gateway for Containers now supports centralized JSON Web Token validation via AuthPolicy custom resource. It validates signature, issuer, lifetime, and audience using trusted JWKS endpoints. Requests with invalid credentials are rejected at the gateway. Policies apply to various routes, inherit or override, and can be combined with WAF. Preview available.
* [\[In preview\] Public Preview: Multi-disk crash-consistent VM restore points for Premium SSD v2 and Ultra Disks on VMs with SCSI disk controller](https://azure.microsoft.com/updates?id=579162). Azure now offers a public preview of multi-disk crash-consistent restore points for VMs using Premium SSD v2 and Ultra data disks with SCSI controllers. Instant Access enables immediate disk restoration. This preview extends existing support to these disk types.
* [\[In preview\] Public Preview: Azure Firewall IPv6 now supports application rules](https://azure.microsoft.com/updates?id=579507). Azure Firewall now supports application rules in IPv6 Public Preview, enabling layer 7 filtering for IPv6 HTTP and HTTPS traffic. The enhancement extends application-level controls to IPv6 and dual-stack deployments, helping customers maintain consistent policies across IPv4 and IPv6 environments.
* [Generally Available: Route maps for Azure Route Server](https://azure.microsoft.com/updates?id=578966). Route maps for Azure Route Server are now generally available in the Azure public cloud. They enable fine-grained control over inbound and outbound routing across hybrid connections, including ExpressRoute, VPN, and Network Virtual Appliances. Capabilities include route summarization, control, path selection, and tagging.
* [\[Launched\] Generally Available: Azure Database for PostgreSQL stable REST API version 2026-10-01](https://azure.microsoft.com/updates?id=579300). Azure Database for PostgreSQL Flexible Server REST API version 2026-10-01 is generally available. The stable release adds maintenance management, immutable backups, multi-tenant encryption with CMKs and FIPS, network migration, Premium SSD v2 storage, version upgrade prechecks, and enhanced autonomous tuning. It supports flexible PostgreSQL version handling and streamlines database administration.
* [\[Launched\] Generally Available: Azure Front Door TLS key exchange policy with post-quantum support](https://azure.microsoft.com/updates?id=577668). Azure Front Door now supports configurable TLS key exchange policies, including hybrid post-quantum key exchange, to prepare for cryptographic threats. Choose Standard, Enhanced, or Custom policies with X25519 support. Hybrid requires TLS 1.3 and protects client-to-edge connections only. Cipher suite can be disabled. Generally Available.
