This week featured 1 update from Microsoft Devblogs.

The update introduces a mandatory token requirement for Dev Proxy API calls, effective from version 3.3.1, affecting all runs that make API requests.

Detailed list:

* [Your best AX fixes are hiding in agent trajectories](https://devblogs.microsoft.com/blog/your-best-ax-fixes-are-hiding-in-agent-trajectories/). The main change is that Dev Proxy now requires a token for API calls, effective from version 3.3.1. This affects all runs that make API requests, as those without a token now return 401 errors. The change is mandatory and cannot be bypassed.
