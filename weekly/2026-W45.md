This week featured 6 updates from Microsoft Azure Updates.

Detailed list:

* [\[In preview\] Public Preview: JWT validation for Application Gateway for Containers](https://azure.microsoft.com/updates?id=576382). - Application Gateway for Containers now supports centralized JSON Web Token validation via the AuthPolicy custom resource. The feature allows validation of token signature, issuer, lifetime, and audience using signing keys from a trusted JWKS endpoint. Requests with invalid or missing credentials are rejected at the gateway. AuthPolicy can be applied to various route types, including HTTPRoute, GRPCRoute, MCPRoute, and can be inherited or overridden at the route level. Optional OAuth Protected Resource Metadata enables discovery of authorization servers and supported scopes. The feature works with Microsoft Entra ID or third-party identity providers.
* [\[In preview\] Public Preview: Multi-disk crash-consistent VM restore points for Premium SSD v2 and Ultra Disks on VMs with SCSI disk controller](https://azure.microsoft.com/updates?id=579162). - Azure has announced a public preview of multi-disk crash-consistent restore points for VMs using Premium SSD v2 and Ultra data disks with SCSI disk controllers. The feature allows agent-less crash-consistent restore points and supports Instant Access, enabling faster disk restoration. Existing support for other disk types remains unchanged.
* [\[In preview\] Public Preview: Azure Firewall IPv6 now supports application rules](https://azure.microsoft.com/updates?id=579507). - Azure Firewall now supports application rules in IPv6 Public Preview, enabling layer 7 filtering for IPv6 HTTP and HTTPS traffic. The enhancement extends application-level controls to IPv6 and dual-stack deployments.
* [Generally Available: Route maps for Azure Route Server](https://azure.microsoft.com/updates?id=578966). - Azure Route Server's route maps are now generally available in the Azure public cloud. These route maps allow fine-grained control over inbound and outbound routing across hybrid connections, including ExpressRoute, VPN, and Network Virtual Appliances (NVAs). They support route summarization, route control, path selection, and route tagging.
* [\[Launched\] Generally Available: Azure Database for PostgreSQL stable REST API version 2026-10-01](https://azure.microsoft.com/updates?id=579300). - Azure Database for PostgreSQL Flexible Server REST API version 2026-10-01 is now generally available. The stable API release includes expanded maintenance management, immutable backups, multi-tenant encryption with customer-managed keys, FIPS configuration, network migration, Premium SSD v2 storage, and major version upgrade prechecks. It also enhances autonomous tuning recommendations and supports more flexible PostgreSQL version handling.
* [\[Launched\] Generally Available: Azure Front Door TLS key exchange policy with post-quantum support](https://azure.microsoft.com/updates?id=577668). - Azure Front Door now supports configurable TLS key exchange policies, including hybrid post-quantum key exchange, to help organizations prepare for evolving cryptographic threats. The service allows selection of predefined Standard or Enhanced policies or a Custom policy to choose supported classical and hybrid post-quantum key exchange groups, such as X25519. Hybrid post-quantum key exchange requires TLS 1.3 and protects client-to-edge connections but does not apply to connections from Azure Front Door to the origin. Additionally, Azure Front Door supports disabling the TLS\_AES\_128\_GCM\_SHA256 cipher suite when TLS 1.3 is configured as the minimum TLS version in the TLS Policy.
