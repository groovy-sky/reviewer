* [Your best AX fixes are hiding in agent trajectories](https://devblogs.microsoft.com/blog/your-best-ax-fixes-are-hiding-in-agent-trajectories/). - The announcement describes a method for improving AI agent performance by analyzing agent trajectories, which record the steps agents take when interacting with a product. It highlights common issues such as incorrect URL guesses, missing documentation, incomplete API endpoints, and outdated help text that cause agents to fail or generate workarounds. The analysis is based on real examples using Dev Proxy to track agent behavior, and it emphasizes that fixes should be made to the product or documentation rather than relying on agent skills.
